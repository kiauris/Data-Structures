# Data Structures

Реализация основных структур данных на C# без использования
готовых коллекций .NET в качестве внутреннего хранилища.

- Стек
- Очередь 
- Списки
  - односвязный
  - двусвязный
  - циклический
- Множество


Для структур реализованы основные операции добавления,
удаления и поиска элементов.

# Функционал

- Реализовано интерактивное консольное меню для работы со структурами

- Добавлен стресс-тест для проверки корректности и производительности

- Проведен анализ временной сложности операций и составлена таблица сравнения с теоретической сложностью

| Структура           |  Push  |  Pop  | Insert / Delete | Find  |
|---------------------|:------:|:-----:|:---------------:|:-----:|
| Стек                |  O(1)  | O(1)  |        -        |   -   |
| Очередь             |  O(1)  | O(1)  |        -        |   -   |
| Односвязный список  |  O(1)  | O(1)  |      O(n)       | O(n)  |
| Двусвязный список   |  O(1)  | O(1)  |      O(n)       | O(n)  |
| Циклический список  |  O(1)  | O(1)  |      O(n)       | O(n)  |

Более подробные результаты в `StressTest\Results`
